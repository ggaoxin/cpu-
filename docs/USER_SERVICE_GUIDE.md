# 语义计算工具库用户服务说明

本文从使用者视角说明当前 19 个功能的输入、输出、页面操作和数据库读写。内容以 Vue 页面、FastAPI 接口和数据库投影代码为准。

## 模型调用约束

- 后端语义模型统一固定为 **GLM-5.2**，通过 `GLM_BASE_URL` 和 `GLM_API_KEY` 调用。
- `GLM_API_KEY` 是必填配置，缺失时后端拒绝启动。
- 前五个功能项（语步识别、自动分类、关键词识别、研究问题识别、引用句识别）共 11 个功能接口，都必须完成 GLM-5.2 API 调用。
- GLM-5.2 连接、超时、解析或输出校验失败时，当次任务返回失败；不使用本地规则或 RAG 结果生成替代的成功响应。
- 规则库和 RAG 仍用于提示词、候选检索、结果校验与解释，不替代 GLM-5.2。

## 一、统一数据库规则

- 系统使用 **1 个统一业务数据库**，通过 `DATABASE_URL` 选择 SQLite 或 MySQL，不是每个工具各建一个数据库。
- 输入通过校验后，`analysis_tasks` 建立任务，`task_items` 保存每个文本、文件或集合任务项。
- 每个成功任务项的完整标准化 JSON 写入 `result_records`，同时写入相应的功能专用投影表。
- 参数校验失败时不建任务；运行阶段失败会保留任务项和错误，但不会生成成功的结果记录或功能投影。
- `workspaces` 只关联任务所属工作空间。默认工作空间在初始化时建立，普通运行不会重复插入。
- 直接上传文件仅用于本次解析，当前执行接口不会自动写入 `files` 或 `documents`；只有显式创建文献集合时才写文献资产表。
- `exports`、`user_feedback`、`external_writebacks`、`audit_events` 是独立的导出、反馈、写回和审计能力，不会在普通工具运行时自动写入。
- `taxonomy_versions`/`taxonomy_nodes`、`ontology_versions`/`ontology_nodes` 是分类体系和本体资源结构；普通调用只记录所用版本，不自动创建这些资源。
- `cluster_revisions`、`cluster_corrections`、`cluster_label_confirmations` 已有表结构，但当前页面没有对应提交操作，普通运行不会写入。

所有功能共同涉及以下 4 张表：

| 表 | 方式 | 保存内容 |
|---|---|---|
| `workspaces` | 引用 | 任务所属工作空间 |
| `analysis_tasks` | 写入/更新 | 工具、输入类型、参数、模型版本、进度、成功/失败数和状态 |
| `task_items` | 写入/更新 | 每个输入项的来源、顺序、状态和错误 |
| `result_records` | 成功时写入 | 完整结果 JSON、工具 ID、后端功能码和结果记录 ID |

## 二、逐功能说明

### 1. 中文摘要语步识别

- 输入：单篇/多篇中文摘要，或 PDF、DOCX、TXT 单文件/批量文件；可设置置信度和语步聚合。
- 输出：研究背景、目的、方法、结果、结论；包含原文、位置、来源、置信度和统计。
- 操作：选择输入方式 → 提交摘要 → 查看逐句语步 → 在任务历史中复查。
- 数据库：共同 4 表；`move_results` 保存标题与统计，`move_segments` 保存逐条语步。

### 2. 英文摘要语步识别

- 输入：单篇/多篇英文摘要，或 PDF、DOCX、TXT 文件；可设置语言、置信度和聚合。
- 输出：五类英文语步，以及原句、位置、来源、置信度和数量统计。
- 操作：提交英文摘要 → 系统逐句识别 → 查看明细和汇总。
- 数据库：共同 4 表；`move_results`、`move_segments`。

### 3. 中文基金项目语步识别

- 输入：PDF、DOCX、TXT 基金申请书，支持单文件/批量；可设置来源章节、并发数和遇错继续。
- 输出：立项依据、研究目标、技术路线、预期成果、应用价值，以及项目标题、章节/页码和统计。
- 操作：上传申请书 → 解析章节 → 查看五类语步和来源。
- 数据库：共同 4 表；`move_results`、`move_segments`。上传文件不自动写 `files`、`documents`。

### 4. 中文科技文献分类

- 输入：标题与摘要至少一项，关键词可选；支持单篇、多篇和文件；可指定分类体系版本。
- 输出：主分类、辅助分类、完整路径、置信度、候选组合、领域标签和确认状态。
- 操作：输入文献 → 查看候选 → 在结果弹窗选择并确认。
- 数据库：共同 4 表；`classification_results`、`classification_candidates`；确认时写 `classification_confirmations` 并更新结果状态。

### 5. 英文科技文献分类

- 输入：英文标题与摘要至少一项，关键词可选；支持单篇、多篇和文件。
- 输出：主辅分类、候选、路径、置信度、跨语言映射和分布报告。
- 操作：提交英文元数据 → 术语映射和分类 → 弹窗复核确认。
- 数据库：共同 4 表；`classification_results`、`classification_candidates`；确认时写 `classification_confirmations`。

### 6. 专业领域科技文献分类

- 输入：必须选择专业领域；标题与摘要至少一项，关键词可选；支持文本和文件。
- 输出：领域匹配、多层级分类、候选、领域标签、置信度和确认状态。
- 操作：选择领域 → 提交文献 → 查看领域内分类 → 人工确认。
- 数据库：共同 4 表；`classification_results`、`classification_candidates`；确认时写 `classification_confirmations`。

### 7. 中文关键词识别

- 输入：中文摘要文本/文件；可设数量、顺序、原形；可用系统词典、已保存词典或一次性术语。
- 输出：关键词、规范词、得分、排名、位置、分类映射、词典命中和统计。
- 操作：输入摘要 → 选择词典模式 → 可保存/加载词典 → 执行识别。
- 数据库：共同 4 表；`keyword_results`、`keyword_items`。保存/加载用户词典时涉及 `dictionaries`、`dictionary_versions`、`dictionary_terms`；一次性术语不保存时不新增版本。

### 8. 英文关键词识别

- 输入：英文摘要文本/文件；可设数量、规范化和顺序；可使用系统或用户英文词典。
- 输出：专业术语/缩写、规范形式、得分、排名、来源、分类映射和统计。
- 操作：输入摘要 → 配置词典 → 抽取和规范化 → 查看/导出。
- 数据库：共同 4 表；`keyword_results`、`keyword_items`；词典操作使用上述 3 张词典表。同名词典保存为新版本，最多保留最近 5 个版本。

### 9. 研究问题识别

- 输入：科技文献片段或全文文本/文件，支持单篇和批量；可提交格式要求。
- 输出：问题句、问题短语、主/子问题结构、来源位置、置信度和统计。
- 操作：提供正文 → 定位问题表达 → 查看问题层次和证据位置。
- 数据库：共同 4 表；`research_question_results`、`research_question_items`。

### 10. 引用情感识别

- 输入：PDF、DOCX、TXT 全文文件；可设上下文窗口、最低置信度、参考文献解析和返回字段。
- 输出：引文标记、引用句、正向/中性/负向情感、证据、上下文、位置、元数据和统计。
- 操作：上传全文 → 抽取引文并判断情感 → 在弹窗切换结果、上下文和参考文献。
- 数据库：共同 4 表；`citation_results`、`citation_items`。文件不自动写入文献资产表。

### 11. 引用意图识别

- 输入：PDF、DOCX、TXT 全文文件；可设上下文、置信度、元数据和训练证据返回。
- 输出：背景、使用、比较、支持、批评等意图，以及证据、上下文、位置、元数据和统计。
- 操作：上传全文 → 结合上下文判断意图 → 查看结果和证据。
- 数据库：共同 4 表；`citation_results`、`citation_items`。文件不自动写入文献资产表。

### 12. 概念定义识别

- 输入：科技全文片段或 PDF、DOCX、TXT 文件；可选择领域、最低置信度、映射和位置返回。
- 输出：概念、规范概念、定义、原句、领域、位置、映射术语和置信度。
- 操作：输入正文 → 识别定义模式 → 查看定义卡片和统计。
- 数据库：共同 4 表；`definition_results`、`definition_items`。

### 13. 通用命名实体识别

- 输入：中英文文本/文件；可选择语言、学科、实体类型、规范化和最低置信度。
- 输出：人物、地点、机构、事件等实体的原文、规范词、类型、位置、上下文、KB ID 和置信度。
- 操作：选择实体范围 → 提交内容 → 查看实体明细和统计。
- 数据库：共同 4 表；`entity_results`、`entity_mentions`。

### 14. 通用科研实体识别

- 输入：科研文本/文件；可配置学科、科研实体类型、规范化、最低置信度和上下文。
- 输出：研究对象、方法、数据、指标、任务等实体及类型路径、位置、上下文和置信度。
- 操作：提交科研内容 → 识别科研实体 → 查看证据；结果可供关系识别复用。
- 数据库：共同 4 表；`entity_results`、`entity_mentions`。

### 15. 专业领域科研实体识别

- 输入：必须选择领域；可指定本体版本、实体类型、最低置信度和 KB ID 返回。
- 输出：领域、本体版本、实体、规范词、类型路径、KB ID、位置和置信度。
- 操作：选择领域 → 提交内容 → 按本体识别 → 查看领域实体。
- 数据库：共同 4 表；`entity_results`、`entity_mentions`。只记录所用本体版本，不自动创建本体资源。

### 16. 实体关系识别

- 输入：文本/文件直接识别，或选择兼容的历史实体结果；可指定领域和最低置信度。
- 输出：主语—关系—宾语三元组、实体 ID、关系类型、证据、置信度和来源记录。
- 操作：选择直接/历史模式 → 识别关系 → 查看三元组和证据。
- 数据库：共同 4 表；`relation_results`、`relation_triples`；历史模式额外写 `record_dependencies`。

### 17. 科技文献深度聚类

- 输入：多篇文献文本、批量 PDF/DOCX/TXT 文件或已有集合；可选维度、算法和类簇数。
- 输出：聚类任务 ID、类簇、代表词、中心文献、成员、相似度、趋势和质量指标。
- 操作：添加文献/选择集合 → 聚类 → 查看质量 → 供标签或综述复用。
- 数据库：共同 4 表；`cluster_runs`、`clusters`、`cluster_memberships`。选择集合时读取 `document_collections`、`documents`、`collection_documents`；只有显式创建集合时才写这 3 表。

### 18. 类簇标签自动生成

- 输入：多篇文献文本、批量文件，或历史聚类任务；可设标签长度、语言和区分度。
- 输出：正式标签、备选标签、置信度、区分度、证据词和生成报告。
- 操作：添加文献/选择聚类 → 生成并校验标签 → 查看标签和证据。
- 数据库：共同 4 表；`cluster_label_results`、`cluster_labels`；复用聚类时写 `record_dependencies`。当前页面不写 `cluster_label_confirmations`。

### 19. 结构化自动综述

- 输入：多篇文献文本、批量 PDF/DOCX/TXT 文件或已有集合；可填主题、语言、溯源开关，并可复用历史聚类。
- 输出：研究问题—方法—进展树、章节、趋势、热点、问题和逐条证据来源。
- 操作：添加文献/选择集合 → 填写主题 → 生成综述 → 查看章节和证据。
- 数据库：共同 4 表；`review_results`、`review_nodes`、`review_sections`、`review_evidence_links`；集合模式读取集合 3 表；复用聚类时写 `record_dependencies`。

## 三、前五类功能的数据库数量

若“前五类功能”指语步识别、自动分类、关键词识别、研究问题识别和引用分析，则它们共用 **1 个数据库**，涉及 **18 张核心表**：通用任务与结果 4 张、语步 2 张、分类 3 张、关键词结果 2 张、用户词典 3 张、研究问题 2 张、引用分析 2 张。

词典 3 表只在保存/加载用户词典时使用；`classification_confirmations` 只在用户确认分类时写入。
