# 深度聚类实现与验证报告

日期：2026-08-13

## 本轮实现结论

完整项目中的 `dc_cluster` 已采用自适应输入表示，并保持 Vue 请求契约为
`id + publication_date + text`：

- 明确且完整地包含标题、摘要、关键词时，才进入结构化加权；
- 普通科研报告、项目材料或无法可靠识别结构的内容直接按 `text` 分段表示；
- 不从首句伪造标题，不生成虚假关键词，也不把发表时间作为聚类语义特征；
- 手工文本清洗后最大 8000 个字符，超限时前后端都会拒绝，不静默截断；
- 文件与数据库集合可以保留完整正文，并从明确的发表日期字段或元数据中读取日期；
- 技术路线采用 BGE-M3 原生稀疏头与字段/片段向量加权；
- 应用场景采用 Domain、Object、Problem 三视图 Core3 表示；
- 当前生产调用链不使用主题库映射。

## 输出补充

聚类响应新增并保留以下可审计内容：

- 每篇文档采用 `structured` 或 `plain_text` 的输入表示；
- 结构识别方式、置信度、参与语义表示的字段或文本片段；
- 文档所属类簇、相似度、关键证据和发表时间；
- 结构化/普通文本数量汇总；
- 基于真实文档年份与类簇归属统计的年度趋势，不生成虚假趋势数字。
