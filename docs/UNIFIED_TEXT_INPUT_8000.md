# 在线测试统一 text 输入与 8000 字限制

日期：2026-08-13

## 统一规则

- 在线测试中的手工单文本和批量文本统一限制为清洗后不超过 8000 个字符；
- Vue 提供实时字数统计和 `maxlength=8000`；
- 后端在创建任务前再次校验，避免绕过前端直接调用 API；
- 文件上传和数据库已有集合不强制截为 8000 字，仍保留全文并由后端解析或分段；
- 不需要字段权重的功能直接处理用户提交的真实 `text`。

## 保留结构识别的功能

自动分类和深度聚类会在 `text` 中存在完整、明确的标题、摘要、关键词标记时
自动解析这些真实字段；结构不完整时直接使用原始 `text`，不伪造字段。

自动分类保留这一能力，是因为 CLC 候选检索优先使用标题与关键词。没有可靠
结构时，候选检索改用原始 `text` 兜底，不再要求用户分别填写三个输入框。

## 直接使用 text 的功能

- 中文/英文摘要语步识别；
- 中文/英文关键词识别；
- 研究问题识别；
- 概念定义识别；
- 通用、科研及专业领域实体识别；
- 实体关系识别；
- 聚类标签生成；
- 结构化自动综述。

基金项目语步和两个引用识别功能当前在线测试仅提供文件输入，因此不增加手工
文本限制。深度聚类仍保持 `id + publication_date + text` 的专用输入契约。

## 验证

- 文本限制、结构解析和批量真实文本传递自检：13 项通过；
- 既有前五项 HTTP/数据库回归：5 项通过；
- Vue 生产构建：通过；
- 页面实际抽查：自动分类、关键词识别、聚类标签和结构化综述均只显示 text，
  并显示 `0 / 8000` 与 8000 字硬限制。
