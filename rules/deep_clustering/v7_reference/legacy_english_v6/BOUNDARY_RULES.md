# TopicFusion v6 边界规则库

v6 不再把规则当作全局兜底分类器，而是作为语义原型与校准判别器之间的第三路证据。规则分为三类：

1. **高优先级研究设计规则**：系统综述、Meta分析、病例报告、随机对照试验、观察性队列、问卷/定性研究、经济评价、野外调查等。此类规则可以覆盖摘要中大量领域术语。
2. **领域方法证据规则**：组学测序、PCR/遗传关联、动物实验、细胞实验、第一性原理、数值模拟、器件设计、材料制备、材料表征等。
3. **成对边界消歧规则**：仅在容易混淆的类别边界上加减分，不直接替代聚类结果。

## 关键技术路线边界

### T12 材料合成与制备 vs T13 材料表征与性能测试
- 出现 `synthesized / prepared / fabricated / hydrothermal / polymerization / deposition / annealing` 等贡献性制备动词时，优先 T12。
- 仅使用 XRD、SEM、TEM、Raman、FTIR 等仪器不代表 T13；这些往往只是合成论文的验证手段。
- 没有新制备过程，且核心贡献是表征、性能测定或力学测试时，判为 T13。

### T22 动物模型与药理干预 vs T08 细胞分子与生化实验
- 实验干预单元是大鼠、小鼠、犬、鱼等完整动物，且有给药、造模、喂养或注射时，优先 T22。
- 仅细胞培养、体外处理、Western blot、蛋白表达和信号通路实验时，优先 T08。
- 动物组织后的分子检测属于实验手段，不改变动物实验的主技术路线。

### T09 组学测序 vs T24 遗传关联与PCR检测
- RNA-seq、单细胞测序、转录组、蛋白组、代谢组、全基因组等高通量全局分析归 T09。
- PCR、qPCR、特定位点基因分型、多态性和目标基因变异检测归 T24。

### T17 工程器件设计 vs T14 数值模拟
- 存在原型加工、器件制备和实测结果时，优先 T17。
- 仅有限元、CFD、Monte Carlo 或器件仿真而无原型验证时，优先 T14。

### T03 临床观察研究 vs T11 成像与诊断检测
- 核心问题是患者结局、风险因素、预后或人群关联时，即便使用影像，也优先 T03。
- 核心贡献是新的诊断、成像、测量技术及其准确性验证时，优先 T11。

### T07 病例报告 vs T10 病理组织诊断
- 文章整体为单例/少量病例报告时，研究设计优先 T07。
- 多样本病理形态、组织染色和免疫组化诊断研究才优先 T10。

## 关键应用场景边界

### 疾病领域 vs A09 医学影像/诊断器械
- 使用 MRI、CT、超声不自动归 A09。
- 如果目标是某疾病的病因、预后或治疗，归相应疾病场景。
- 如果核心贡献是新成像方法、分割算法、探头、诊断设备或检测流程，归 A09。

### A11 兽医水产 vs 人体疾病场景
- 犬、猫、鱼、家畜、野生动物和水产养殖为明确主对象时，优先 A11。

### A16 电子半导体器件 vs A17 光学光子/天线射频
- 光电探测器、晶体管、柔性电子和半导体传感器优先 A16。
- 天线、波导、微波、太赫兹、超表面和光通信优先 A17。

### A21 化学催化/碳转化 vs A15 材料
- 材料仅作为催化剂载体，而核心任务是 CO2 转化、电催化或光催化时，优先 A21。

### A29 药物递送 vs 疾病诊疗
- 核心贡献是脂质体、纳米载体、制剂和递送系统时，优先 A29；临床疗效与疾病结局仍归疾病场景。

## 使用原则

- 宽泛词汇不能硬覆盖，例如 `measurement`、`analysis`、`model`、`ultrasound`。
- 强覆盖只开放给边界清晰的研究设计和少数专用方法类别。
- 对第一、第二候选差距较小的文献输出 `needs_review=true`，保留主簇和辅簇，不强行制造虚假确定性。
